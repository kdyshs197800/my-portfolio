리빙팡팡 컬러 팔레트

어두운 무대 위에 금빛 조명이 떨어지고, 해결 장면에서는 에메랄드 네온이 켜집니다. 채널 썸네일 36장과 장면 이미지 221장에서 실제로 뽑은 색으로 만든 홈페이지용 팔레트입니다.

영상 속 색 비율

어두운 배경을 뺀 선명한 색만 모은 대략적인 비율입니다. 따뜻한 금색 계열이 절반 가까이, 청록·에메랄드 계열이 4분의 1을 차지합니다.

금색·주황 (조명, 동전, 자막) 약 45% 청록·에메랄드 (해결 장면 네온) 약 25% 빨강·파랑 등 기타 약 30%

글자 대비 (WCAG)

본문 글자는 4.5 이상(AA), 큰 제목은 3 이상이면 웹 접근성 기준을 통과합니다.

쓰는 규칙

  • 골드는 버튼과 숫자에흰 배경에서는 글자색으로 쓰지 말고 버튼 배경·강조 띠로만 씁니다.
  • 레드는 경고에만한국 주식은 상승이 빨강입니다. 수익률·가격 숫자에 레드를 쓰면 의미가 뒤집혀 보입니다.
  • 에메랄드 버튼 글자는 차콜흰 글자는 대비 3.2로 본문 크기에서 기준 미달입니다.
  • 한 화면에 강조색 하나골드와 에메랄드를 같은 줄에 나란히 강조하지 않습니다.
  • 글꼴은 Pretendard앞으로 나올 영상의 자막·배지와 같은 글꼴입니다. 아래 '글꼴 불러오기' 줄을 꼭 함께 넣으세요.
  • 숫자는 고정폭 숫자표·가격에는 font-variant-numeric: tabular-nums 로 자리를 맞춥니다.

CSS 토큰

홈페이지 스타일시트 맨 위에 붙여 넣으면 됩니다.
:root {
  /* 주컬러 */
  --lp-gold: #FFB703;        /* 버튼, 숫자 강조 */
  --lp-gold-soft: #FFD166;   /* 자막색, 호버 */
  /* 보조컬러 */
  --lp-stage: #14161C;       /* 페이지 배경 */
  --lp-panel: #1F242D;       /* 카드 */
  --lp-ink: #F8FAFC;         /* 본문 글자 */
  --lp-mute: #9CA3AF;        /* 보조 글자 */
  /* 포인트 컬러 */
  --lp-emerald: #19A572;     /* 해결·완료, 보조 버튼 */
  --lp-emerald-hi: #2DD4A3;  /* 다크 배경 링크 */
  --lp-teal-deep: #0F766E;   /* 흰 배경 링크 */
  --lp-alert: #E63946;       /* 경고 표시만 */
  /* 글꼴 (아래 ① 불러오기 줄이 head에 있어야 방문자에게 적용됨) */
  --lp-font: "Pretendard Variable", "Pretendard", "Noto Sans KR", "Malgun Gothic", sans-serif;
}
body { font-family: var(--lp-font); }

글꼴 불러오기

CSS 토큰은 글꼴 이름만 지정합니다. 이 한 줄을 홈페이지 <head> 안에 넣어야 방문자 기기에서도 Pretendard가 보입니다.
<link rel="stylesheet" crossorigin
  href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css">

확인은 시크릿 창이나 휴대폰으로 하세요. 내 PC에는 글꼴이 설치돼 있어 빠뜨려도 제대로 보입니다.
